# 🐱 Image Classifier

A deep learning web application built with **TensorFlow** and **Streamlit** that classifies uploaded images as either **Cat** or **Dog**.

## 🚀 Features

- Upload JPG, JPEG, or PNG images
- AI-powered image classification
- Confidence score
- Image preview
- Responsive Streamlit interface

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- Streamlit
- OpenCV
- NumPy
- Pillow

## 📂 Project Structure

```
Image-Classifier/
│── app.py
│── best_model.keras
│── requirements.txt
│── README.md
│── .gitignore
```

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📷 Example

Upload a cat or dog image and the application predicts the class with a confidence percentage.
